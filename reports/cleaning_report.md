## Missing-value decisions

Empty and whitespace-only fields become missing values in memory. CSV represents
these as empty fields; the output schema identifies nullable types. A future SQLite
loader must convert those empty fields to SQL NULL. Literal strings such as `NA`
are not automatically treated as missing. Required keys and required operational
fields cannot be missing: validation stops publication if they are.

- **`orders.order_approved_at` (160 missing):** Missing approval may reflect a canceled/created order; delivered exceptions also exist. The precise source cause is not established. Decision: Retain NULL and the order. Flag delivered exceptions; exclude the missing stage only from future approval-duration calculations.
- **`orders.order_delivered_carrier_date` (1,783 missing):** Several statuses have not reached carrier handoff; some delivered orders also lack this event. Decision: Retain NULL. Flag delivered exceptions; do not replace it with approval or purchase time.
- **`orders.order_delivered_customer_date` (2,965 missing):** Non-delivered statuses often lack delivery time; delivered exceptions remain unresolved. Decision: Retain NULL. Flag delivered exceptions; never use the estimated date as actual delivery.
- **`products.product_category_name` (610 missing):** The source did not supply the category; its underlying cause is unknown. Decision: Retain NULL and product. Add flag_category_missing; do not assign an observed category or a fabricated category label.
- **`products.product_name_length` (610 missing):** Product-name metadata is absent; underlying cause is unknown. Decision: Retain nullable integer; do not assume a zero-length name.
- **`products.product_description_length` (610 missing):** Description-length metadata is absent; underlying cause is unknown. Decision: Retain nullable integer; do not assume zero or infer text that is not supplied.
- **`products.product_photos_qty` (610 missing):** Photo metadata is absent; underlying cause is unknown. Decision: Retain nullable integer; missing does not establish that the product has no photos.
- **`products.product_weight_g` (2 missing):** Physical metadata is absent; underlying cause is unknown. Decision: Retain NULL; do not impute a median or substitute zero. Populated zero weights are retained and flagged separately.
- **`products.product_length_cm` (2 missing):** Physical metadata is absent; underlying cause is unknown. Decision: Retain NULL; later size calculations must disclose incomplete measurements.
- **`products.product_height_cm` (2 missing):** Physical metadata is absent; underlying cause is unknown. Decision: Retain NULL; do not substitute another dimension.
- **`products.product_width_cm` (2 missing):** Physical metadata is absent; underlying cause is unknown. Decision: Retain NULL; do not substitute another dimension.
- **`reviews.review_comment_title` (87,658 missing):** The supplied review has no populated title; a score can still be present. Whitespace-only titles add no text. Decision: Retain review and score; label with flag_title_missing and serialize missing text as an empty CSV field.
- **`reviews.review_comment_message` (58,274 missing):** The supplied review has no populated message; the reason the respondent omitted it is unknown. Decision: Retain review and score; label with flag_message_missing. Preserve nonblank prose verbatim.

Missing child records, geographic observations, and translations are coverage gaps,
not blank required identifiers. Preserve parent records and label the gaps using
flags. Original missing counts are also recorded in the manifest.
